حزمة مصدر SALO Flutter — الإصدار 1.4.0+5

تتضمن الحزمة تطبيق Flutter، ومصادقة Firebase Email/Password، وCloud Functions وFirestore/Storage rules وملفات الفهارس وFirebase Hosting headers، إضافةً إلى توثيق الإعداد والنشر.

بُني APK Debug قابل للتثبيت يدويًا وسُلّم منفصلًا باسم SALO_1.4.0_debug.apk؛ لا يُعد إصدار متجر. لم يتم نشر الخدمات على مشروع Firebase أو إنشاء Firestore. لا تتضمن الحزمة Backend أو تصديرًا موثوقًا للبيانات القديمة؛ لذا لم تُرحّل الحسابات/المحادثات السابقة. تتطلب تهيئة iOS ملف GoogleService-Info.plist.

لم يتضمن الأرشيف مفتاح Service Account أو مفتاح توقيع إصدار. ألغِ مفتاح الخدمة الذي رُفع سابقًا من Google Cloud IAM، واحتفظ بمفتاح توقيع Android منفصلًا. راجع FIREBASE_DEPLOYMENT_AR.md وFIREBASE_SETUP_STATUS_AR.md قبل النشر.
